LEVEL 1 — Data Cleaning (Basic but strict)

You MUST check:

Duplicate SKUs
Missing stock values
Negative quantities (very common error)
Text inconsistencies (categories, supplier names)
Numbers stored as text

👉 Goal:
Clean dataset → Inventory_Clean
 Use the formula =IF(ISBLANK(A2), 0, A2) in an adjacent column to populate 0 if the cell is blank, and retain the original value otherwise. ( for missing values)
=MAX(0, A1) (for negative)
for duplicates goto data tab abd remive duplicates
for text consistencies 
Fix Inconsistent Capitalization: Combine with PROPER, UPPER, or LOWER.
Example: =PROPER(TRIM(A2)) makes text look like "John Doe".
Remove Non-Printable Characters: If there are hidden characters, use CLEAN.
Example: =TRIM(CLEAN(A2))
